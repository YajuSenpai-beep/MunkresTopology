# figures_src —— 手工重建插图的 **TikZ 源码**

> 2026-09-16 建档。六张**人工重建**的插图源文件；编译产物进 `images\`，
> 由书里既有的 `\munkresfig[宽]{图号}` 引用（`\includegraphics` 不带扩展名，**优先 PDF**）。

---

## 这是什么

| | |
|---|---|
| **内容** | 图 1.1 / 1.2 / 1.3 / 2.1 / 2.2 / 2.3（原书第 1–2 章的六张编号插图） |
| **做法** | **按图里的信息重建**，不是描摹像素：圆是解析圆、阴影是参数化平行线、自由曲线是**显式三次贝塞尔** |
| **量从哪来** | 全部**逐列/逐行实测**原书扫描件，注释里写明了每个关键数值是怎么量出来的 |
| **为什么重建** | 描摹（骨架→逐段拟合）有固有毛病：曲线有拼接痕迹、线宽跳变。调参消不掉 |

## 怎么用

```bash
make figures          # figures_src/fig_N.M.tex → images/N.M.pdf（六张全出）
```

单张手动：

```bash
cd figures_src && xelatex fig_2.2.tex
```

**产物必须落到 `images\<图号>.pdf`**（去掉 `fig_` 前缀）。
书里 `\munkresfig[1.0]{2.2}` → `\includegraphics{images/2.2}` 不带扩展名，
xelatex 按 `.pdf` 优先于 `.png` 的顺序挑；所以 **PDF 一进 `images\`，书自动改用矢量版**，
**章节 `.tex` 一个字都不用动**。

---

## 两条注意

1. **bounding box 就是原图 PNG 的像素框**，六张逐个精确相等
   （如 2.2 是 `(0,0) rectangle (1080,320)`，`images/2.2.png` 正好 1080×320）。
   所以 PDF 顶替 PNG 后**版面尺寸完全不变**。
2. **依赖**：需要 `fontspec` + `tikz`（标签用 Arial 近似原书那款加重斜体）。
   用 `xelatex` 编，不要用 pdflatex。
