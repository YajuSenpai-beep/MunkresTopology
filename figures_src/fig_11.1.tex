%
% ══ 按用户意见重做（「圆圈的样式都有偏差，曲线不光滑，需要重新思考几何样式」）══
% 病根：原稿把**几乎所有圆都画成了贝塞尔链**（28~55 行那几十段 curves），
%       只有 2 张用了 ellipse、3 张用了 circle。贝塞尔拼接的圆必然有接缝和抖动，
%       而且右组还**漏画了一整张圆**（画成贝塞尔的那张）。
% 正解：这些图元本来就是正圆 —— 一律 `\draw (cx,cy) circle (r)`，解析画。
%
% 参数量法（原书 600dpi 裁切 src_hi/11.1.png，2142×899）：
%   · 左组先证「同心」：从墨迹 bbox 中心打 720 条射线，**每个角度都数到 7 个环**；
%     再网格搜索圆心令「七环半径跨角度的离散度」最小 ⇒ 圆心 px(441.0,449.0)，
%     离散度合计仅 12.8px（七环 × 720 条射线），同心性成立。
%   · 标定：拿原稿那两张 ellipse 的半径 22.8 / 58.4 当锚 —— 拟合出的对应环
%     半径是 42.1 / 108.1 px ⇒ **1.8313 px = 1 画布单位**（与图 10.1 同尺度）。
%   · 右组：圆评分搜索（圆周落墨比例），得四张圆**左缘都是 x=786.5** ⇒ 同点相切。
%   · 线宽实测 8.5px ⇒ 4.6 画布单位。

\usepackage{fontspec}

\begin{tikzpicture}[x=1pt, y=-1pt, line width=4.6pt, line cap=round, line join=round]

  %% ════ 左组：7 张同心圆，圆心 (251.9, 248.9) ════
  %% 半径由内向外（实测 px 42.1/108.1/169.4/230.8/295.9/361.2/427.5 ÷ 1.8313）
  \foreach \r in {23.0, 59.0, 92.5, 126.0, 161.6, 197.2, 233.4}{
    \draw (251.9,248.9) circle (\r);
  }

  %% ════ 右组：4 张圆，左缘同点 x=786.5 相切 ════
  %% 原稿只有前 3 张（66.9/126.1/193.4），中间那张 r=161.1 被画成了贝塞尔链 —— 补回
  \draw (854.2,248.5) circle (67.7);

  \draw (947.0,248.5) circle (161.1);
  \draw (977.0,248.5) circle (193.3);

  % 钉死画布：否则超出的图元/控制点会把页面撑大，1:1 回比就失准
  \pgfresetboundingbox
  \path[use as bounding box] (0,0) rectangle (1191,499);
